
## Visão Geral do Desafio (DIO)
Chat interativo que responde com base no conteúdo de arquivos PDF. 
Para isso, são utilizados conceitos de IA generativa, embeddings e buscas vetorizadas para estruturar um sistema capaz de entender, processar e responder perguntas a partir de documentos específicos. 
Essa abordagem permite que seja elaborado um modelo personalizado de assistência virtual focado em um conjunto de informações proprietárias, sem depender unicamente do conhecimento geral de modelos pré-treinados.

## Cenário
Pesquisador necessita revisar e correlacionar diversos artigos científicos relacionados à classificação de dados. 
Entretanto, à medida que acumula mais documentos, torna-se cada vez mais difícil extrair informações relevantes e conectar ideias entre diferentes textos.
Diante disso, visando facilitar esse processo e utilizando inteligência artificial, implementa-se um sistema de busca inteligente capaz de:

✅ interpretar os PDFs,

✅ organizar informações e 

✅ gerar respostas relevantes com base no conteúdo carregado.


## Objetivos do projeto

✅ carregar arquivos PDF contendo informações relevantes;

✅ implementar um sistema de busca vetorial para indexar e recuperar informações dos PDFs;

✅ utilizar inteligência artificial para gerar respostas baseadas no conteúdo dos documentos carregados;

✅ desenvolver um chat interativo em que seja possível realizar perguntas e obter respostas contextuais fundamentadas nos arquivos.

Classificação de dados é o processo de organizar e categorizar informações em diferentes grupos ou categorias com base em características, relevância ou sensibilidade. Esse processo é essencial para gerenciar, proteger e utilizar os dados de maneira eficiente em organizações, sistemas de informação e outros contextos.  
   
### Principais objetivos da classificação de dados:  
1. **Proteção de dados sensíveis**: Identificar informações confidenciais, como dados pessoais, financeiros ou estratégicos, para aplicar controles de segurança adequados.  
2. **Gerenciamento eficiente**: Facilitar o acesso e o uso dos dados, garantindo que as informações sejam organizadas de forma lógica e intuitiva.  
3. **Conformidade legal e regulatória**: Garantir que os dados estejam em conformidade com normas legais ou regulamentares, como a LGPD (Lei Geral de Proteção de Dados) no Brasil ou o GDPR (Regulamento Geral de Proteção de Dados) na União Europeia.  
4. **Tomada de decisão**: Classificar os dados permite identificar quais são mais relevantes ou prioritários, auxiliando na tomada de decisões estratégicas.  
   
### Como funciona a classificação de dados?  
A classificação geralmente envolve as seguintes etapas:  
1. **Identificação dos dados**: Avaliar os tipos de informações disponíveis.  
2. **Definição de critérios**: Estabelecer categorias ou níveis de classificação, como "confidencial", "restrito", "público", entre outros.  
3. **Classificação propriamente dita**: Atribuir cada conjunto de dados a uma categoria com base nos critérios definidos.  
4. **Aplicação de políticas**: Implementar medidas de segurança e gerenciamento adequadas para cada categoria, como restrições de acesso ou criptografia.  
   
### Exemplos de categorias de classificação de dados:  
- **Público**: Informações que podem ser compartilhadas sem restrições, como dados disponíveis em sites ou materiais de marketing.  
- **Interno**: Dados que são acessíveis apenas dentro de uma organização e não devem ser divulgados externamente.  
- **Confidencial**: Informações sensíveis, como dados de clientes ou estratégias corporativas, que requerem alto nível de proteção.  
- **Restrito**: Dados altamente críticos e sigilosos, como segredos industriais ou informações protegidas por leis.  
   
A classificação de dados pode ser realizada manualmente ou por meio de ferramentas automatizadas que utilizam inteligência artificial e algoritmos para identificar padrões e categorizar informações.  
   
Esse processo é fundamental para garantir a segurança, eficiência e conformidade no gerenciamento de informações em qualquer organização ou sistema.
